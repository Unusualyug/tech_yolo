# Empirical protocols — no results yet

This directory contains **runnable protocols, blank result templates, and
software self-checks only**. No camera capture, model inference, labeled
dataset, timing campaign, translated-template rating, or human-participant
study was performed while preparing this revision. Every empirical cell is
`NO DATA` until the author supplies real logs and personally verifies the
numbers.

The 1,000-case seeded `alert_selection_audit.json` is generated by
`tests/test_synthetic_regression.py`. Its 68.1% value is a **unit-test
artifact only** and appears in the paper solely as software verification; it is
not an experiment result and no experiment script generates it.


   gitignored; they are working data, not citable results.

## Experiment A — latency / runtime cost

Collect **at least 500 camera frames per setting** at `416`, `640`, and `832`
input sizes on the declared hardware. The optional recorder writes separate
capture, inference, TTS-synthesis, playback, and rendering rows. Report median
and p95 for each stage and setting. Do not call a short or incomplete run a
result.

```bash
python3 experiments/latency_benchmark.py --self-check
python3 experiments/latency_benchmark.py --emit-blank \
  --output experiments/results/latency_blank.json
python3 experiments/latency_benchmark.py \
  --summarize experiments/results/latency.jsonl \
  --hardware-manifest experiments/hardware_manifest.json \
  --output experiments/results/latency_results.json
```

## Experiment B — detection quality and vocabulary/confidence grid

Use **200–300 labeled COCO, LVIS, or own images**. Declare the report split,
a separate tuning split, frozen prompts, and the report-split hash before
generating predictions. **Never tune on the reported images.** Use
`pycocotools` or Ultralytics `val` for mAP@0.5; report precision, recall,
mAP@0.5, and speed. Negative or worse results are acceptable and must be
reported as-is.

The grid is `{455, 20, 50, 80 prompts} × {0.15, 0.25, 0.35}` = 12 cells. The
full maintained prompt set contains 455 unique prompts; the reduced prompt
sets must be frozen in `vocab_manifest.json` before predictions are made.

```bash
python3 experiments/detection_eval.py --self-check
python3 experiments/detection_eval.py --emit-blank \
  --output experiments/results/detection_blank.json
python3 experiments/detection_eval.py --run --backend pycocotools \
  --dataset-manifest experiments/dataset_manifest.json \
  --ground-truth /path/to/instances_report.json \
  --predictions /path/to/predictions.json \
  --latency-log experiments/results/latency.jsonl \
  --confidence 0.15 --imgsz 640 --vocab-size 455 \
  --output experiments/results/detection_cell.json
python3 experiments/vocab_confidence_grid.py --self-check
python3 experiments/vocab_confidence_grid.py --emit-plan \
  --output experiments/results/vocab_grid_blank.json
python3 experiments/vocab_confidence_grid.py --run \
  --dataset-manifest experiments/dataset_manifest.json \
  --vocab-manifest experiments/vocab_manifest.json \
  --ground-truth /path/to/instances_report.json \
  --predictions-dir /path/to/grid_predictions \
  --latency-log experiments/results/latency.jsonl \
  --output experiments/results/vocab_confidence_grid.json
```

`Ultralytics val` is also available through
`detection_eval.py --run --backend ultralytics --weights ... --data ...`, but
its dataset classes are not arbitrary open-vocabulary prompts; custom-prompt
cells require frozen predictions evaluated with the pycocotools adapter.

## Experiment C — alert replay and the research question

The paper's research question is: **Does alert-first narration make users
notice a designated object faster or more often than confidence-first
narration?** A replay of detection logs can measure alert *delivery* and delay,
not user noticing or benefit.

Choose alert objects **in advance** in `alert_manifest.json`. Setting
`TRINEXIS_ALERT_MANIFEST` freezes `/set_alerts`, writes a manifest hash into
every detection record, and prevents post-hoc alert selection. Replay the same
real `/export_logs` frames through alert-first and confidence-first ordering,
subject to the declared speech cooldown, and report delivery rate and mean
alert-to-speech delay. Complete the example from real speech-enqueue events.

```bash
python3 experiments/alert_replay.py --self-check
python3 experiments/alert_replay.py --emit-blank \
  --output experiments/results/alert_replay_blank.json
python3 experiments/alert_replay.py --run \
  --alert-manifest experiments/alert_manifest.json \
  --detection-log experiments/results/export_logs.json \
  --event-log experiments/results/speech_events.jsonl \
  --output experiments/results/alert_replay_results.json
```

Explicitly synthetic/fixture rows are rejected. The 68.1% synthetic check is
retained only as a `tests/` unit/regression test that can fail under a broken
selector.

## Experiment D — checked-language speech ratings

The UI exposes 72 language codes and 62 top-level speech templates. The ten
languages without a top-level template use the **English template fallback**;
the UI states this. No language is claimed verified. Sample **5–10 languages**
with native speakers or reliable bilingual raters, prepare **10 announcements**
per language, and rate correctness and naturalness **1–5**. Listen to sample
gTTS/Google Translate speech audio and to a few languages yourself. Report
only the checked languages; say the remaining 72-language claims are unchecked.

```bash
python3 experiments/language_eval.py --self-check
python3 experiments/language_eval.py --emit-worksheet \
  --languages Hindi,Gujarati,Bengali,Tamil,Spanish \
  --worksheet experiments/results/language_ratings_template.csv
python3 experiments/language_eval.py --emit-blank \
  --output experiments/results/language_rating_blank.json
python3 experiments/language_eval.py --summarize \
  --ratings experiments/results/language_ratings.csv \
  --checked-languages Hindi,Gujarati \
  --output experiments/results/language_rating_results.json
```

The language list above is an **example**, not a verified sample. Do not report
comprehension, translation quality, or assistive benefit from template counts.
